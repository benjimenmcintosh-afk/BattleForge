BATTLE FORGE ALL-IN BUILD

This is a clean Vite project containing the large local prototype.
To use it:
1. Back up your current Battle Forge folder.
2. Replace the contents of the project with these files, or copy src/main.js and src/style.css plus index.html/package.json.
3. In Visual Studio's terminal run: npm install
4. Then run: npm run dev
5. Open the localhost URL Vite gives you.

The local build includes the planned frontend/gameplay systems.
Real accounts, cloud saves, matchmaking, payments, and persistent online leaderboards require a backend/database and are not faked as live services here.
